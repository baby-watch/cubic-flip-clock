## 流程

1. 确认提交当前 1.1.0 版本，应用安装文件位于 package 目录。
2. 核对公开仓库已同步代码、简体简介和测试记录。
3. 可选创建 1.1.0 Release 并附安装 ZIP，便于下载。指南没有将 GitHub Release 列为硬性要求。
4. 给 `sales@clocteck.com` 发邮件，附公开仓库地址、功能、交互方式与测试固件。
5. clocteck 检查元数据、可安装性、基础安全性及设备兼容性，通过后才上架。

不是推送到 GitHub 就自动进入商店；指南也没有要求必须给 holocubic-apps 仓库提交 PR。
