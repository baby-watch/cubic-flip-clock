# 验证记录与限制

验证日期：2026-09-09；固件：1.210；分辨率：320×240。

## 显示与日期

早期开发版的左右倾斜、黑白配色、秒显示切换和清屏修订已由使用者实机验收。1.0.0 保持数字图集、动画和底层清屏方案，新增 16 像素公历日期及 13 像素农历，格式为 yyyy年M月d日 星期X / 农历X月X日。

设备 1.0.0 已运行并报告 2026年9月9日 星期三、农历七月廿八。新增排版仍需使用者最终观感确认。

农历表由 lunar-javascript 1.7.7 生成，覆盖 1900—2100 年；超出范围显示提示。实际 Lua 查询代码与香港天文台 2024—2030 年 2,557 天逐日对照通过，包含闰日、春节和闰月；另有越界、纪元日和农历文字测试。没有声称覆盖范围内每一天均已与官方数据独立对照。

浏览器 ICU 在 2027-02-06 与香港天文台结果有差异，因此预览改用与设备相同的月表，不再调用浏览器农历生成显示。

## 字体

从源字体内嵌的 OFL 许可确认 Noto Sans SC 授权，生成重新命名的独立子集并保留版权。1.0.0 的 12、13、16 像素字体合计 11,796 字节；1.1.0 加入皮肤与动效名称后为 18,348 字节。替换早期来源未确认的天气字体。

## 生命周期：文档与实测

上游 README_LUA.md 说明，应用管理器向 IPC endpoint app-lifecycle 发布 app.started / app.stopped，附 id 和 instance_id。该事件用于外部观察，不是要求即将销毁的应用接收退出钩子。

1.0.0 不再注册没有文档承诺的 app.on("exit")。保留幂等 stop/shutdown、重载旧实例清理和 app.exiting() 轮询，但不把系统一定调用 stop/shutdown 作为前提。系统返回手势未被拦截。

通过独立临时服务订阅官方 IPC，执行五轮启动、退出；每轮均收到匹配的 app.started / app.stopped，五次 instance_id 不同。退出后的内存不是连续递减。短时样本不能证明长期绝无泄漏，也不能证明全部强制终止场景。

## 发布默认行为

正式版默认不写周期日志和启动截图。只有部署者显式创建应用目录中的 diagnostics.flag 才启用诊断；该开关不打包、不提交 Git。临时观察服务在验证结束后停用并移除。

## 设置恢复（1.0.0）

配色和秒显示在用户操作时写入 settings.json，启动读取；不依赖退出回调。实际 Lua 偏好模块通过四种组合、重新加载、损坏数据、读取失败及写入失败测试（tools/test_preferences.lua）。网页实际点击切换后刷新保留设置，损坏数据恢复默认值。设备启动读回白底黑字、隐藏秒设置；使用者已确认退出重开能够恢复。未进行拔电测试。网页和设备分别保存偏好。

## 1.1.0 设备适配与黑屏排查

七种皮肤采用逐卡压缩图集，普通帧和余辉帧共 1,680 张，压缩资源总计 2,817,710 字节。黑白普通帧沿用原 RGB565 数据。余辉通过额外画布透明叠加，回弹通过上下半页行压缩绘制，不进行运行时逐像素调色。

临时测试入口加载正式 main.lua，通过正式 key.on 回调切换皮肤、动效和秒显示，并核验 settings.json。16 组组合通过，覆盖七种皮肤的余辉与回弹，以及余辉大卡片和回弹小卡片。测试期间仅替换应用的时间读取函数以加速分钟变化，不改系统时钟。测试后恢复正式入口和用户设置。按键回调验证不等同于使用者对快速倾斜手感和实机外观的验收。

用户报告偶发黑屏。2026-09-09 原版采样期间，自动休眠和定时灭屏均关闭；19 次读数显示亮度为 100、sleeping=false、应用在运行、计数推进，没有错误，空闲堆约为 125,668—126,496 字节。该轮未复现黑屏，因此根因尚未确认，也不能排除长期泄漏。下一次黑屏应在按返回键之前采集现场状态。

没有为了掩盖黑屏而关闭系统休眠或周期性强制设置亮度。当前诊断开关用于继续采集故障证据，正式安装包不包含此开关。

## 动效负载对比

2026-09-09，同一设备、冰蓝皮肤、显示秒、亮度 100；每种模式读取三个样本。以下为启动后稳定样本，短时数据不能替代温度测量、耗电测量或长期压力测试。

| 模式 | CPU0 | CPU1 | 平均更新耗时 |
| --- | --- | --- | --- |
| 原版 | 16—17% | 5—6% | 约 2.68—2.78 ms |
| 余辉（图像透明度优化后） | 19% | 13% | 约 3.05—3.07 ms |
| 机械回弹 | 20—21% | 9—10% | 约 3.77—3.79 ms |

余辉从对象整体透明度改为图像自身透明度，减少额外合成层开销；优化前稳定 CPU 约为 21% / 18—19%。更新耗时只覆盖脚本 update 和相关绘制调用，不包括全部系统后台工作。没有设备温度读数，不能据此判定微热是否正常。

设置保存曾出现 JSON 解码参数错误：assert(value, message) 在成功时也返回 message。现将读回值存入局部变量再解码，回归测试先失败后通过，并补充实机检查 settings_saved 状态。该错误被捕获且应用继续运行，尚无证据表明它是此前黑屏的原因。
