# 验证记录与限制

验证日期：2026-09-09；固件：1.210；分辨率：320×240。

## 显示与日期

早期开发版的左右倾斜、黑白配色、秒显示切换和清屏修订已由使用者实机验收。1.0.0 保持数字图集、动画和底层清屏方案，新增 16 像素公历日期及 13 像素农历，格式为 yyyy年M月d日 星期X / 农历X月X日。

设备 1.0.0 已运行并报告 2026年9月9日 星期三、农历七月廿八。新增排版仍需使用者最终观感确认。

农历表由 lunar-javascript 1.7.7 生成，覆盖 1900—2100 年；超出范围显示提示。实际 Lua 查询代码与香港天文台 2024—2030 年 2,557 天逐日对照通过，包含闰日、春节和闰月；另有越界、纪元日和农历文字测试。没有声称覆盖范围内每一天均已与官方数据独立对照。

浏览器 ICU 在 2027-02-06 与香港天文台结果有差异，因此预览改用与设备相同的月表，不再调用浏览器农历生成显示。

## 字体

从源字体内嵌的 OFL 许可确认 Noto Sans SC 授权，生成重新命名的独立子集并保留版权。12、13、16 像素字体合计 11,796 字节；替换早期来源未确认的 177,480 字节天气字体。

## 生命周期：文档与实测

上游 README_LUA.md 说明，应用管理器向 IPC endpoint app-lifecycle 发布 app.started / app.stopped，附 id 和 instance_id。该事件用于外部观察，不是要求即将销毁的应用接收退出钩子。

1.0.0 不再注册没有文档承诺的 app.on("exit")。保留幂等 stop/shutdown、重载旧实例清理和 app.exiting() 轮询，但不把系统一定调用 stop/shutdown 作为前提。系统返回手势未被拦截。

通过独立临时服务订阅官方 IPC，执行五轮启动、退出；每轮均收到匹配的 app.started / app.stopped，五次 instance_id 不同。退出后的内存不是连续递减。短时样本不能证明长期绝无泄漏，也不能证明全部强制终止场景。

## 发布默认行为

正式版默认不写周期日志和启动截图。只有部署者显式创建应用目录中的 diagnostics.flag 才启用诊断；该开关不打包、不提交 Git。临时观察服务在验证结束后停用并移除。

## 设置恢复（1.0.0）

配色和秒显示在用户操作时写入 settings.json，启动读取；不依赖退出回调。实际 Lua 偏好模块通过四种组合、重新加载、损坏数据、读取失败及写入失败测试（tools/test_preferences.lua）。网页实际点击切换后刷新保留设置，损坏数据恢复默认值。设备启动读回白底黑字、隐藏秒设置；使用者已确认退出重开能够恢复。未进行拔电测试。网页和设备分别保存偏好。
